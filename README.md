# Fundamentos de Kotlin: Sintaxe e Controlo de Fluxo 🚀

Repositório dedicado aos estudos introdutórios da linguagem Kotlin, abordando os conceitos fundamentais da sintaxe moderna, inferência de tipos e controlo de fluxo.

---

## 📌 Conteúdos Abordados

* **Declaração de Variáveis**: Diferença entre variáveis mutáveis (`var`) e imutáveis (`val`).
* **Tipos de Dados Primitivos e Inferência**: Manipulação de inteiros, números decimais, caracteres, cadeias de texto e valores booleanos com inferência automática de tipo.
* **Estruturas Condicionais**: Utilização de `if / else` como expressões de atribuição direta.
* **Expressão `when`**: Equivalente moderno ao `switch/case`, permitindo validações por padrão e intervalos de valores.
